## LedgerDirect

Accept crypto, token and stablecoin payments in your shop — directly on the XRP Ledger,
without a payment intermediary.


| | |
|---|---|
| [ledger-direct-core-php](https://github.com/ledger-direct/ledger-direct-core-php) | Platform-independent payment core |
| [ledger-direct-magento2](https://github.com/ledger-direct/ledger-direct-magento2) | Magento 2 |
| [ledger-direct-shopware6](https://github.com/ledger-direct/ledger-direct-shopware6) | Shopware 6 |
| [ledger-direct-woocommerce](https://github.com/ledger-direct/ledger-direct-woocommerce) | WooCommerce |
| [ledger-direct-magento2-vuestorefront2](https://github.com/ledger-direct/ledger-direct-magento2-vuestorefront2) | Headless checkout via Vue Storefront |
| [ledger-direct-sandbox](https://github.com/ledger-direct/ledger-direct-sandbox) | Local development environment |

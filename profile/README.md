## LedgerDirect

Accept XRP and stablecoin payments in your shop — directly on the XRP Ledger, non-custodial,
without a payment intermediary.

### Shop plugins

| | |
|---|---|
| [ledger-direct-shopware6](https://github.com/ledger-direct/ledger-direct-shopware6) | Shopware 6 |
| [ledger-direct-magento2](https://github.com/ledger-direct/ledger-direct-magento2) | Magento 2 |
| [ledger-direct-woocommerce](https://github.com/ledger-direct/ledger-direct-woocommerce) | WooCommerce |
| [ledger-direct-prestashop](https://github.com/ledger-direct/ledger-direct-prestashop) | PrestaShop |

### Foundation

| | |
|---|---|
| [ledger-direct-core-php](https://github.com/ledger-direct/ledger-direct-core-php) | Platform-independent payment core, shared by every plugin |
| [ledger-direct-e2e](https://github.com/ledger-direct/ledger-direct-e2e) | End-to-end tests against the XRPL testnet for all four plugins |
